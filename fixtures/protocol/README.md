# Golden protocol fixtures

Generated by `scripts/native/generate-fixtures.ts` from one deterministic
table drive through the real session layer. TypeScript
(`scripts/native/tests/fixtures.test.ts`) and Unreal
(`LongTable.Protocol.*` automation) read the same files:

| File | Contents |
| --- | --- |
| `manifest.json` | Protocol version, manifest id and digest, every wire vocabulary list, schema key lists, concealed keys, limits. |
| `player-projection.json`, `host-projection.json`, `public-projection.json` | One mid-play projection per role with its canonical text. |
| `dealer-cues.json` | Every dealer cue frame from the drive with canonical text. |
| `receipts.json` | Accepted, committed, duplicate, stale-version, nothing-to-confirm, unauthorized-role, bid-outside-manifest and not-between-hands receipts. |
| `client-messages.json` | Hello for each role, a resume hello, one intent per kind, a resync. |
| `authority-messages.json` | Welcome per role, projection, receipt, replay, dealer-cue and schema-rejected error. |
| `rejections.json` | Payloads that must be rejected, with the expected code and dotted path. |
| `counterfactual.json` | Host and public projections built from the same public facts with every concealed fact replaced; both must re-encode byte-identically. |
| `dev-room.json` | Room file for the local authority harness (fixture tokens only). |

Regenerate with `node scripts/native/run-ts.mjs scripts/native/generate-fixtures.ts`;
`--check` verifies the committed files are current.
