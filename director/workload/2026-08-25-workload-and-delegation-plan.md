# Workload and delegation plan — post-debate

## Accounting rule

The percentages apply to **direct specialist work**, measured with 100 scoped
work units. Director intake, moderation, debate management, synthesis,
acceptance, and reporting are excluded from OpenAI's direct-work share. A
provider receives credit only for authenticated, attributable output that
satisfies its packet. Attempts, unavailable sessions, and quarantined work
receive zero credit.

## Execution tools and permission boundary

GitHub, Slack, Linear, Claude, Cursor, Perplexity, Firecrawl, and Antigravity
are used only through authenticated and project-scoped interfaces. GitHub is
the code/evidence authority. Slack is coordination after the channel and
message scope are confirmed. Linear work is not placed in the unrelated
Project Uppercut team. Host completion runners, live LangGraph execution,
parallel external dispatch, and regex-based privacy controls are **permitted**;
they are activated only when the exact project configuration, single-writer or
idempotency design, budget, redaction limitations, and external-write scope are
ready and recorded. “Permitted” is not the same as “currently configured.”

## Checkpoints

1. **Pre-stage:** provider authentication, isolated worktrees, exact base,
   owned surfaces, cost ceilings, and no conflicting writers.
2. **Rules checkpoint (12%):** experienced-player critique of the named manifest
   before large implementation credit.
3. **Halfway report (50 units):** actual provider shares, exact candidates,
   test evidence, risks, availability deviation, and adjustment proposal.
4. **Paired-proof checkpoint:** WebGL full-hand proof plus Quest seated slice;
   no networking or avatar claims beyond observed evidence.
5. **Heavy test and completion report:** invariants, browser/WebGL, device,
   authority, accessibility, safety, rights, and provenance.
6. **Human test/critique:** experienced Bid Whist, beginner, age/accessibility,
   event host, and cultural advisor cohorts.
7. **Kickback or acceptance:** findings return to the owning provider; unchanged
   exact candidate receives independent acceptance and current CI/security.
