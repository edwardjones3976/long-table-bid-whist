## Director decision

Continue the smallest reversible technical candidate because the owner has
already fixed the material direction and the implementation provides direct
evidence without creating a network or public-service commitment.

1. **Platform:** Meta Quest remains the target product surface. The current
   browser build is an interaction/rules proof, not the final runtime.
2. **Engine/toolchain:** Retain the headless TypeScript rules kernel and React
   room for this candidate. Defer the Quest-native engine choice until human
   task evidence and Meta input/avatar requirements are explicit.
3. **Rules architecture:** Preserve the pure reducer, versioned Strict Table
   manifest, seeded replay, legal action helpers, and seat-safe projection.
4. **Networking:** Local/offline proof first. Any private multiplayer phase must
   add a server-authoritative deck, event log, reconnection, and AI substitution
   boundary before security acceptance.
5. **Human identity:** No built-in cast. Each occupied human seat uses that
   participant's own Meta avatar in the target runtime. Open seats are the
   truthful browser fallback.
6. **Dealer/host:** AI Dealer may be a clearly non-human robot presentation.
   Human Host manages the room and between-hand pacing, never committed cards,
   deals, bids, tricks, or scores.
7. **Cultural direction:** Foundational Black American spirit stays light and
   environmental: hospitality, social energy, wood/felt/brass, table etiquette,
   and rights-clean original ambience; never demographic casting or stereotype.
8. **Rights:** No music recording ships in this candidate. Host music remains
   off and external; a safe file format is not clearance.
