# Director workflow for The Long Table

This directory applies the modular project-bootstrap workflow from
[`edwardjones3976/director-orchestrator`](https://github.com/edwardjones3976/director-orchestrator)
to this project.

## Provenance

- Workflow source: `edwardjones3976/director-orchestrator`
- Source branch: `main`

- Protocol: `docs/project-bootstrap-protocol.md`

The workflow source is a reference and coordination system, not the game's
implementation target. This project's private repository is
`edwardjones3976/long-table-bid-whist`; the current Codex project task is its
coordination surface. Slack and paid providers are not required for the current

## Operating sequence

`BOOTSTRAP` -> `BOUNDED RESEARCH` -> `INDEPENDENT POSITIONS` -> `ONE REBUTTAL`
-> `DIRECTOR/OWNER DECISION` -> `PRE-STAGE` -> `PROVIDER CHUNKS` -> `0–50%`
-> `MIDWAY EVIDENCE` -> optional `RESHAPED` -> `50–100%` -> `HEAVY TESTING`
-> `TECHNICAL CANDIDATE / REVIEW_READY` -> `HUMAN USER TEST` -> `KICKBACK` or
`ACCEPTANCE` -> `COMPLETE`.

Unavailable provider positions do not get simulated. The current accelerated
cycle recorded an OpenAI position, no Claude/Cursor responses, no rebuttal, and
a provisional Director continuation based on the owner's explicit direction
and a reversible local candidate. `COMPLETE` remains unavailable before human
acceptance.

## Workload and capacity

- OpenAI: full Director/control-plane duties, excluded from the percentages.
- Claude: 60% direct-production target as Chief Programmer.
- Cursor: 28% as Project Secretary and full-spectrum repository partner.
- Gemini/Antigravity: 7% bounded specialist and backup production.
- Perplexity: 4% strict public-evidence research production.
- External OpenAI/Codex: 1% only when separately owner-authorized, outside the
  Director runtime, and followed by different-provider exact-candidate review.

The Director is never a specialist assignment target. The operating-capacity
target is 95% productive coordination and 5% reserve; the reserve is not planned
idle time.

Local project work and pushes to the confirmed private repository are authorized
at a zero-dollar external-provider budget. The Director will select the initial
engine/toolchain after the prototype specification establishes the smallest
useful technical surface. New spending, public release, service deployment,
shared host-audio transmission, or broader external effects remain separately
gated. Everything under `sources/` remains read-only.
