# The Long Table native program — canonical overlay

This directory is the current Director record for the complete native Meta
Quest product. It supersedes the earlier browser-prototype scope without
rewriting or erasing that evidence. The existing WebXR candidate remains a
rules, protocol, and interaction oracle; it is not the product target.

## Frozen product decision

- Ship one Unreal Engine 5.7.4 application for Meta Quest 3/3S, built as a C++
  project with Blueprint presentation.
- Keep the existing TypeScript rules engine and table service authoritative.
  Unreal sends typed intents and receives role-bound projections; it never
  adjudicates Bid Whist from physics, animation, or Blueprint state.
- Make hands and Touch controllers first-class, interchangeable inputs with one
  semantic action vocabulary and an explicit preview/cancel/confirm commit
  boundary.
- Use the signed-in participant's Meta avatar through an isolated presence
  adapter when available. The fallback is tracked hands/controllers, nameplate,
  and seat marker—never a stock human cast member.
- The AI Dealer is a clearly non-human robot presenter. A human host can run
  invitations, pacing, moderation, queues, announcements, substitutions, and
  ceremonies but cannot request, deserialize, change, or infer concealed state.
- Express Foundational Black American spirit lightly through hospitality,
  table ritual, environmental warmth, conversational pacing, and advisor-led
  detail. Avoid costumes, caricature, fixed avatars, imitation voices, and a
  theme-park treatment.
- Bundle only original or documented rights-cleared visual, voice, composition,
  recording, sample, and likeness assets. Ship no third-party jazz or blues
  recording by assumption. Host music is external/off by default; a future
  in-space path requires rights, consent, moderation, and platform review.
- Regex, blacklist, keyword, and best-effort redaction are prohibited as
  privacy or disclosure controls. Player, host, public, AI, telemetry, and
  provider payloads are separate closed schemas constructed from allowlists.

## Complete delivery shape

1. **Native Foundation / First Deal** — toolchain proof, authoritative protocol,
   Quest hands/controllers, mixed-reality placement, robot dealer, one-trick
   tutorial, 13-card fan, input equivalence, and two-device concealed-state
   proof.
2. **Private Game Night** — full rules, four participants, AI seats, private
   rooms, reconnect, host transfer, between-hand substitution, voice safety,
   accessibility, and a full hosted match on devices.
3. **Long Table House** — one application containing arrival house and tables,
   multi-table directory, events, queues, clubs/leagues, public-only spectator
   feed, floor-host operations, ceremonies, and repeat-event evidence.
4. **Release acceptance** — exact-candidate QA, CI/security/privacy/rights,
   performance and soak testing, Quest-device matrix, experienced-player and
   target-audience critique, accessibility and cultural review, store checks,
   owner acceptance, then merge/release authority.

The words `COMPLETE`, `device-passed`, `human-passed`, `store-ready`, and
`released` remain evidence-bound. Local implementation success cannot satisfy a
physical headset, external account, human cohort, or owner gate.

## Provider code ownership

- Claude: TypeScript authority, protocol, core table/runtime, composition root.
- Cursor: native XR hands/controllers, presence, MR/VR environment adapters.
- Grok: private-session, host, reconnect, voice/safety and social adapters.
- Gemini Antigravity: isolated Long Table House queue/rotation/standings core
  produced from a closed public contract without private repository context.
- OpenAI: cross-module QA, evidence binding, findings, kickback and acceptance;
  no product-code ownership.
